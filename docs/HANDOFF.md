# Local handoff

Text the Web researches a public page from a URL/question and returns a concise,
sourced response through Photon Spectrum. The saved demo is a real Mac Messages
same-account developer self-chat, with live TinyFish Fetch and Research. It is
not proof of iPad delivery, an independent peer, or a managed cloud identity.

## Review and run

The local `dist-release/text-the-web-mvp.zip` contains application source, locked
dependencies, tests, docs and explicitly selected redacted evidence. Its
`RELEASE-MANIFEST.json` lists each file's SHA-256 and size. The adjacent
`.sha256` file checks the ZIP. Private originals, credentials, Messages data,
SQLite state, dependencies and the other projects in this workspace are excluded.

After extracting, use a terminal inside `text-the-web`:

```sh
npm ci
npm run check
npm test
npm run build
RESEARCH_MODE=fixture npm run dev
```

Open `http://127.0.0.1:3100`. This defaults to explicitly labeled fixture research
and offline browser messaging. `npm run demo` is a fixture terminal walkthrough.
Neither command constitutes new live iMessage proof. Setup requires Node 22.13+
and npm; Python 3.9+ is needed only to rebuild the local ZIP with
`npm run release:pack`. No cloud deployment is required.

The archive omits credentials and budget databases for privacy. **Do not enable
live mode in an extracted copy to replenish exhausted research allowances.**
Continue live work only from the original state after the operator reviews an
explicit bounded allowance using existing free credits. After the initial
handoff the user authorized exactly two additional native requests; both were
consumed successfully, leaving no allowance remaining. Old state was retained.
